# Tetris Block Puzzle

Responsive Tetris-style arcade game built with vanilla HTML, CSS, and JavaScript.

## Features

- Responsive board that fits desktop and mobile screens
- Start, pause, and restart controls
- Next-piece preview and ghost-piece landing guide
- Level, line, score, and best-score tracking
- Soft drop and hard drop scoring
- Touch controls for smaller screens
- Consecutive line-clear combo bonuses
- Back-to-back Tetris scoring bonus

## Controls

- `Left / Right` move piece
- `Up` or `X` rotate
- `Down` soft drop
- `Space` hard drop
- `Enter` start
- `P` pause

## Run

Open `index.html` in a browser.
