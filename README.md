# Tetris Block Puzzle V2

Responsive Tetris-style arcade game built with vanilla HTML, CSS, and JavaScript.

## Features

- Responsive board that fits desktop and mobile screens
- Start, pause, and restart controls
- Hold piece mechanic with once-per-drop refresh
- Three-piece queue preview and ghost-piece landing guide
- Level, line, score, and best-score tracking
- Short lock delay for grounded piece adjustments
- Soft drop and hard drop scoring
- Touch controls plus mobile Hold and Drop buttons
- Consecutive line-clear combo bonuses
- Back-to-back Tetris scoring bonus

## Controls

- `Left / Right` move piece
- `Up` or `X` rotate
- `Down` soft drop
- `Space` hard drop
- `C` or `Shift` hold piece
- `Enter` start
- `P` pause

## Run

Open `index.html` in a browser.
